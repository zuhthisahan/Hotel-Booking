# 🏨 Hotel Room Booking Application

A full-stack web application that allows users to book hotel rooms, manage reservations, and handle admin-level hotel operations. Built with **React (Vite)** on the frontend and **Spring Boot** on the backend.

---

## 🚀 Features

### 👤 User
- Browse available hotel rooms
- Book a room with dates
- View booking history
- Edit booking reservation

### 🔐 Admin
- Add, update, or delete room listings
- Manage users
- Manage Bookings

---

## 🛠️ Tech Stack

| Layer        | Technology         |
|-------------|--------------------|
| Frontend    | React (Vite), TypeScript, Bootstrap |
| Backend     | Spring Boot, Java, Spring Security |
| Database    | MySQL |
| API         | RESTful APIs       |
| Others      | JWT Auth, Axios, etc. |


## ⚙️ Installation

### Clone the repo
```bash
git clone https://github.com/your-username/hotel-booking-app.git
cd hotel-booking-app

1. Backend Setup
cd backend
# Configure your database in application.yml (not pushed to GitHub)
./mvnw spring-boot:run

2. Frontend Setup
cd frontend
npm install
npm run dev

🔐 Environment Variables
spring.datasource.url=
spring.datasource.username=
spring.datasource.password=
```
